LoRa Mesh Air Quality Network

An ESP32 + SIM7080G cellular gateway built for a LoRa mesh air-quality sensor network deployed at Toronto's Meadoway, paired with a custom 4-layer electrochemical sensor breakout board for the network's sensor nodes. The gateway collects readings from the mesh, buffers and manages them locally, and publishes them to the cloud over a cellular uplink, where data is managed and visualized using InfluxDB and Grafana.
