Software Defined Radio: RF Subsystem

3-stage RF front-end PCB for a software-defined radio
Altium LTSpice RF Design PCB Design

Jan. 2026 – Apr. 2026

Overview

Designed and fabricated the RF front-end for a software-defined radio. The subsystem filters an 8–16 MHz RF input, downconverts it into in-phase (I) and quadrature (Q) signals, then filters and amplifies the resulting baseband signals.

RF Front-End

  • Bandpass filter: designed a 3rd-order LC Butterworth filter with 50Ω input and output matching for the 8–16 MHz RF passband.
  • Quadrature mixer: implemented separate I and Q double-balanced mixer paths using RF transformers and Schottky diodes for RF downconversion.
  • I/Q amplifier: designed active low-pass amplifier stages to remove mixer products above 96 kHz while providing the required baseband gain.

Simulation & Testing

  • Filter simulation: used LTSpice to verify the Butterworth filter response and component values before PCB fabrication.
  • Filter testing: measured 8.55 MHz and 14.82 MHz band edges using an oscilloscope frequency response analysis sweep.
  • Mixer testing: applied 9 MHz quadrature LO signals and measured the expected frequency components at the mixer outputs using oscilloscope FFT analysis.
  • Amplifier testing: measured 20.32 dB gain from a 50 mV input before the amplifier failed during testing.

Debugging

  • Transformer replacement: replaced a failed RF transformer after no output was measured from the mixer, restoring mixer operation.
  • TXEN bypass: bypassed a faulty TX enable switch with jumper connections to restore the RF signal path.
  • Amplifier failure: traced the amplifier supply to approximately 3.3 V instead of the required 4.5 V minimum before the OPA1642 failed during testing.
  • PCB interconnect: corrected three misaligned connector pins between the subsystem PCB and mainboard using jumper wires.
