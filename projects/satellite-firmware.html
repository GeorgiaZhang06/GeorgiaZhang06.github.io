Satellite Firmware: UTAT Space Systems

Zephyr RTOS + MCUboot bring-up for a custom STM32 OBC
Zephyr RTOS MCUboot STM32 DTS overlays
project photo

May 2026 – Present

Overview

Onboarding UTAT Space Systems' on-board computer (OBC) firmware to Zephyr RTOS with MCUboot, targeting a custom STM32-based board. This involved setting up a west workspace for the finch-firmware repository and building toward a T2 star topology for the OBC.

Work So Far

  • Set up a Zephyr west workspace for the satellite firmware repository.
  • Wrote custom device-tree (DTS) flash-partition overlays for the board.
  • Got MCUboot booting a signed application from slot0 with a working sysbuild configuration.
  • Demonstrated a live slot0-to-slot1 firmware swap.
