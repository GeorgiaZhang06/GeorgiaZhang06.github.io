Voice-Controlled “Flappy Bird” Game

FPGA-based game controlled by microphone amplitude on the Terasic DE1-SoC
Verilog FPGA VGA Audio DSP

Oct. 2025 – Dec. 2025

In compliance with university academic integrity policies, the source code for this project is not public.

System Architecture

  • Input handling: a microphone interfaces with an audio controller to translate volume into the player object’s vertical velocity.
  • VGA rendering: a hardware arbiter manages simultaneous draw and erase requests from the player and pillar modules to the VGA display.
  • State control: a finite state machine governs the game states, transitioning from a start menu to active gameplay when audio exceeds a threshold, and halting on collision detection.
  • Scorekeeping: a binary-coded decimal counter tracks score and outputs it to a 7-segment hex display.

Module Operation Logic

  1. The player module waits for a clock tick, erases its previous position through the arbiter, updates physics based on vertical velocity, and redraws its coordinates.
  2. The pillar module shifts left, checks for screen wrap-around, calculates a new gap, and issues its own VGA draw and erase requests.
  3. The collision module continuously evaluates the overlapping coordinate boundaries of the player, pillars, and screen edges.

Debugging and Implementation Fixes

  • Gap generation: the initial random number generator for pillar gaps failed, so it was replaced with a deterministic counter that cycles through pre-set gap positions.
  • VGA artifacts: visual streaking during pillar rendering was resolved by changing the drawing sequence from row-by-row to column-by-column.
  • Image persistence: background artifacts remained during game state changes, leading to a dedicated background-clearing FSM.
  • Score accuracy: the scoring logic was incorrectly incrementing, and it was fixed to count only when the pillar FSM resets its position.

Hardware

  • FPGA : Terasic DE1-SoC with Intel Cyclone V
  • Display : VGA monitor at 640x480
  • Audio : microphone through the WM8731 audio codec
