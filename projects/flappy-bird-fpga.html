Voice-Controlled "Flappy Bird" Game

FPGA-based game controlled by microphone amplitude on the Terasic DE1-SoC
Verilog FPGA FSM VGA I2C ModelSim

Oct. 2025 – Dec. 2025

In compliance with university academic integrity policies, the source code for this project is not public.

Overview

A hardware-based side-scrolling game implemented in synthesizable Verilog on the Terasic DE1-SoC. Microphone amplitude controls the player's vertical velocity: louder input produces a larger upward velocity. The game runs entirely on FPGA hardware and renders gameplay through a custom VGA interface.

Key Features

  • Audio-controlled movement : microphone amplitude is converted into player vertical velocity, allowing louder sounds to move the player upward faster.
  • VGA rendering : custom hardware renders the player, pillars, and background at 640x480 resolution.
  • Hardware game control : FSMs manage game states, object movement, rendering, collision detection, and score updates.
  • Hardware verification : wrote SystemVerilog testbenches and used ModelSim to test individual modules before hardware integration.

System Architecture

  • Audio subsystem : interfaces with the Wolfson WM8731 audio codec through I2C and processes microphone samples to determine signal amplitude.
  • Player physics : updates vertical position using velocity and applies gravity between audio inputs.
  • VGA arbiter : coordinates draw and erase requests from the player, pillars, and background modules through an FSM.
  • Collision detection : checks coordinate boundaries between the player, pillars, and screen edges to determine game-over conditions.
  • Scorekeeping : tracks the score with BCD logic and displays the result on the DE1-SoC seven-segment displays.

Debugging

  • VGA artifacts : eliminated visual streaking by changing pillar rendering from row-by-row to column-by-column drawing.
  • Obstacle generation : replaced a failing random number generator with deterministic gap-position cycling to produce stable obstacle placement.
  • Background persistence : added a dedicated background-clearing FSM to remove artifacts during game state transitions.
  • Score logic : corrected score updates to occur when the pillar FSM resets its horizontal position.

Hardware

  • FPGA : Terasic DE1-SoC with Intel Cyclone V
  • Display : VGA monitor at 640x480
  • Audio : microphone through the WM8731 audio codec
