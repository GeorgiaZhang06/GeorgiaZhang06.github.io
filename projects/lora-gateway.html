LoRa Mesh Air Quality Network

Gateway and electrochemical breakout board for a LoRa mesh sensor network
FreeRTOS ESP32 AWS IoT Core LoRa Cellular (SIM7080G) PCB Design

Overview

An ESP32 + SIM7080G cellular gateway built for a LoRa mesh air-quality sensor network deployed at Toronto's Meadoway. The gateway collects readings from the mesh, buffers and manages them locally, and publishes them to the cloud over a cellular uplink.

Firmware Architecture

  • A FreeRTOS task architecture covering the uplink state machine, cloud connection handling, configuration management, and modem power control.
  • Data is published over MQTT to AWS IoT Core.
  • RTC-persisted state carries key variables across deep sleep cycles, so the gateway resumes correctly after each wake.

Sensor Hardware

  • Designed a 4-layer electrochemical sensor breakout board for the network's sensor nodes.
