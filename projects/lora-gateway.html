LoRa Mesh Air Quality Network

Embedded gateway and electrochemical sensor hardware for an off-grid air-quality monitoring network
C++ FreeRTOS ESP32 LoRa AWS IoT Core

May. 2026 – Aug. 2026

Overview

An off-grid air-quality network that collects measurements from distributed sensor nodes and sends them to the cloud. Nodes communicate over LoRa, while an ESP32 gateway uses a SIM7080G cellular modem to upload data to AWS IoT Core.

The system combines gateway firmware with an electrochemical sensor interface for long-term outdoor deployment, with low power, reliable communication, and nanoamp-level measurements as key constraints.

Gateway Firmware

  • Structured the ESP32 gateway with FreeRTOS tasks for sensing, LoRa communication, cellular communication, and cloud transmission.
  • Implemented duty cycling to coordinate data collection while limiting power consumption.
  • Published sensor data to AWS IoT Core using MQTT over the SIM7080G.
  • Fixed an ESP32 boot failure caused by a GPIO12 strapping-pin conflict by delaying serial and downlink initialization.
  • Resolved cellular brownouts caused by LDO current limits during modem transmission by powering the modem from the battery supply.

Electrochemical Sensor Hardware

A 4-layer electrochemical breakout board plugs into the sensor-node PCB and provides the analog front end and ADC for low-current measurements.

  • Used the LMP91000 potentiostat to interface with electrochemical sensors.
  • Used the ADS122C04 24-bit ADC for nanoamp-level currents beyond the sensor node's ATmega328 ADC resolution.
  • Matched the existing sensor-node interface so the board could connect as a plug-in module.

System Data Flow

Sensor nodes forward measurements through the LoRa mesh to the ESP32 gateway, which sends them through the SIM7080G to AWS IoT Core. Data is stored in InfluxDB and visualized with Grafana.

Key Constraints

  • Low power: Battery-powered nodes use duty-cycled sensing and communication.
  • Low current: Electrochemical sensors produce nanoamp-level signals.
  • Connectivity: Nodes use LoRa and the gateway uses cellular.
  • Deployment: Hardware operates without continuous grid power.
