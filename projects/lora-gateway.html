LoRa Mesh Air Quality Network

Embedded gateway and electrochemical sensor hardware for an off-grid air-quality monitoring network
C++ FreeRTOS ESP32 ATmega328 LoRa AWS IoT Core MQTT PCB Design KiCad ADS122C04 LMP91000

Overview

An off-grid air-quality monitoring network designed to collect environmental measurements from distributed sensor nodes and send them to the cloud. Sensor nodes communicate over a LoRa mesh network, while an ESP32 gateway collects the data and uses a SIM7080G cellular modem to upload it to AWS IoT Core.

My work focused on the gateway firmware and the electrochemical sensor interface used by the sensor nodes. The system was designed for long-term outdoor deployment, so power consumption, reliable communication, and low-current sensor measurements were key constraints.

Gateway Firmware

  • Structured the ESP32 gateway firmware using FreeRTOS tasks for sensor collection, LoRa mesh communication, cellular communication, and cloud transmission.
  • Implemented duty-cycled operation so the gateway could coordinate sensor data collection while limiting cellular and system power consumption.
  • Used MQTT over the SIM7080G cellular modem to publish sensor data to AWS IoT Core.
  • Debugged an ESP32 boot failure caused by a GPIO12 strapping-pin conflict by moving software serial initialization into the required runtime functions and delaying downlink setup.
  • Traced cellular communication failures to LDO current limits during modem transmission. The modem was moved from the gateway's regulated supply to the battery supply, eliminating the brownouts.

Electrochemical Sensor Hardware

I designed and built a 4-layer electrochemical breakout board that plugs into the sensor-node PCB. The board provides the analog front end and ADC needed to measure the low-current output of electrochemical sensors.

  • Used the LMP91000 potentiostat analog front end to interface with electrochemical sensors.
  • Used the ADS122C04 24-bit ADC to measure nanoamp-level sensor currents beyond the resolution available from the sensor node's ATmega328 ADC.
  • Designed the PCB around the existing sensor-node interface so the electrochemical board could be connected as a plug-in module.

System Data Flow

Sensor measurements are collected by the sensor nodes and forwarded through the LoRa mesh to the ESP32 gateway. The gateway manages the received data and sends it through the SIM7080G cellular modem to AWS IoT Core for cloud processing and visualization.

Key Constraints

  • Low power: Nodes operate from battery power with duty-cycled sensing and communication.
  • Low current measurement: Electrochemical sensors produce signals in the nanoamp range.
  • Wireless communication: Sensor nodes use LoRa while the gateway uses cellular connectivity.
  • Outdoor deployment: Hardware must operate without continuous access to grid power.
