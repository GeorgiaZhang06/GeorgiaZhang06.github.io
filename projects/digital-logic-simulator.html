Digital Logic Simulator

Bare-metal circuit simulator on the DE1-SoC FPGA board
Bare-metal C MMIO NIOS-V DE1-SoC VGA / PS2
project photo
In compliance with university academic integrity policies, the source code for this project is not public.

Overview

This ECE243 project is an interactive digital logic circuit simulator implemented on the NIOS-V processor running on the DE1-SoC development board. The system is written entirely in bare-metal C: no operating system, no hardware abstraction layer: with every feature implemented through direct interaction with memory-mapped I/O (MMIO).

The simulator supports both combinational and sequential logic. A user describes a circuit in a file, compiles it, and loads it into memory; the simulator builds the circuit and lets the user modify its inputs live using a PS/2 keyboard. The circuit is rendered on a VGA monitor with wire states drawn in red or green, and smaller combinational circuits can automatically generate a truth table.

Hardware Interaction

All peripherals are controlled by reading from and writing to fixed physical memory addresses:

  • VGA Controller: pixel data is written directly to a memory-mapped framebuffer.
  • PS/2 Keyboard: input is handled by polling the PS/2 data register.
  • HEX Displays & LEDs: driven by writing bitmasks to their respective MMIO registers.
  • Circuit Memory: compiled circuit data is loaded into SDRAM at address 0x40000000 using GDB.

The simulator itself is compiled into a RISC-V ELF binary and executed directly on the processor.

Circuit Description & Compilation

  1. The circuit is designed and described in a .log file, with each gate entry on its own line, in the format:
    [GATE TYPE] [INPUT 1 ID] [INPUT 2 ID] [OUTPUT ID] [X COORDINATE] [Y COORDINATE]
    Note: when defining a MUX gate, the wire at index (INPUT 2 ID + 1) must be free: it's assigned to the multiplexer's select input.
  2. The .log file is dragged into the Logipile.exe compiler, which converts it into a .bin binary.
  3. The binary is moved to the working directory and written into memory at 0x40000000 using the restore command in GDB:
    restore .bin binary 0x40000000

Controls

The PS/2 keyboard controls which screen is displayed and lets the user navigate and edit input wires.

  • UP / DOWN: navigate selection between input wires (selected wire is highlighted in purple and bolded).
  • 0 / 1: set the selected input wire's value.
  • ENTER: toggle the homescreen / instruction page.
  • T: show the truth table, when available (not available for sequential circuits with latches).
  • KEY0: read memory at 0x40000000 and load the new circuit onto the VGA.

Output Displays

  • The VGA monitor shows the instruction page on reset or ENTER, the circuit during normal operation, or the truth table on T.
  • The HEX display shows "notbl" when a truth table isn't available: e.g. for circuits with too many inputs/outputs, or sequential circuits.
  • The LEDs show the state of the output wires, indexed by wire number.
